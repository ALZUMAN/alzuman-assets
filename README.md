# ALZUMAN — الزومان

موقع سبائك ذهب ٩٩٩.٩ لمتجر الزومان (بريدة، السعودية). موقع صفحة واحدة (single page)
بسبع مشاهد سردية مع سكرول تفاعلي، بدون أي اعتماد على ملفات فيديو.

## البنية

| مسار | الوصف |
|---|---|
| `index.html` | الصفحة الكاملة (Hero، مشهد السبيكة، العبارات، اختيار الوزن، الثقة، الفوتر) |
| `style.css` | كل الأنماط والحركات (CSS فقط، بدون مكتبات خارجية) |
| `script.js` | منطق السكرول، السعر الحي، حاسبة الوزن، الحركات التفاعلية |
| `alzuman-logo.png` | الشعار الكامل (يُستخدم في الـ Hero) |
| `alzuman-logo-light.png` | نسخة فاتحة للشعار (تُستخدم في الفوتر الكحلي) |

الموقع Static بالكامل، بدون أي build step — يُنشر على Vercel مباشرة (Framework: Other).

## أصول غير مستخدمة (مستبعدة من النشر عبر `.vercelignore`)

هذه الملفات موجودة في المستودع للمرجع فقط ولا يستخدمها الموقع، ومستبعدة من كل نشر
عبر `.vercelignore` حتى لا تُثقل حجم الـ deployment:

- `alzuman-bar.glb`, `alzuman-bar-999.glb` — موديل ثلاثي الأبعاد، للمرجع فقط.
- `scene1-ivory.mp4`, `scene2-sand.mp4`, `scene3-gold.mp4` — مقاطع فيديو **فاشلة
  التشغيل فعليًا** (ترميز `-g 1` يسبب تلفًا رغم أن `ffprobe` يقرأها سليمة). حركة
  السبيكة في الموقع مبنية بالكامل بـ CSS/SVG بدلًا منها.
- ملفات `hf_*.mp4` — مخرجات توليد فيديو غير مستخدمة في الموقع.

## المنطق التقني المهم

- **فتح نافذة السبيكة (المشهد الثاني)**: يعتمد على `scrollY` بمنطق بكسلي ثابت
  (نسبة من ارتفاع الـ Hero عبر `offsetHeight`/`offsetTop`)، وليس على
  `getBoundingClientRect` الهش.
- **دوران السبيكة (rotateY)**: مزيج من تقدّم السكرول داخل مشهد السبيكة وحركة
  الماوس/اللمس، محدود بـ ±8 درجة.
- **السعر الحي**: يبدأ من 4183.40$ للأونصة ويتذبذب عشوائيًا ±2.4$ كل 5 ثوانٍ.
- **حاسبة الوزن**: السعر = `((سعر الأونصة + 50) / 31.1035) × 3.75 × الوزن بالغرام`،
  ويُعاد حسابه تلقائيًا مع كل تحديث لسعر الأونصة.
