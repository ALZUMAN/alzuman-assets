# ALZUMAN — الزومان

موقع سبائك ذهب ٩٩٩.٩ لمتجر الزومان (بريدة، السعودية). موقع صفحة واحدة (single page)
بسبع مشاهد سردية مع سكرول تفاعلي.

## البنية

| مسار | الوصف |
|---|---|
| `index.html` | الصفحة الكاملة (Hero، مشهد السبيكة، العبارات، اختيار الوزن، الثقة، الفوتر) |
| `style.css` | كل الأنماط والحركات |
| `script.js` | منطق السكرول، السعر الحي، حاسبة الوزن، تحميل فيديو السبيكة |
| `alzuman-logo.png` | الشعار الكامل (يُستخدم في الـ Hero) |
| `alzuman-logo-light.png` | نسخة فاتحة للشعار (تُستخدم في الفوتر الكحلي) |

الموقع Static بالكامل، بدون أي build step — يُنشر على Vercel مباشرة (Framework: Other).

## فيديو مشهد السبيكة (المشهد الثاني)

النافذة المؤطرة في المشهد الثاني تعرض `scene1-ivory.mp4` (مُحمَّل عند الحاجة فقط،
`preload="none"`، ويُشغَّل بمجرد فتح النافذة عبر JS) مباشرة من مسار GitHub الخام:

```
https://raw.githubusercontent.com/ALZUMAN/alzuman-assets/main/scene1-ivory.mp4
```

**تصحيح مهم**: كان يُعتقد سابقًا أن `scene1-ivory.mp4` و`scene2-sand.mp4` و
`scene3-gold.mp4` تالفة (بسبب ترميز `-g 1`). تم التحقق فعليًا بفحص عميق:
- فُحصت البنية الداخلية للملفات (MP4 box structure, stsd, avcC, stss, stsz, stco) —
  كلها سليمة ومتّسقة.
- فُحص الترميز عبر `ffprobe`: H.264 (yuv420p) قياسي، 960×540 — ترميز مدعوم من كل
  المتصفحات الحديثة.
- فُحص فك التشفير الكامل عبر `ffmpeg -xerror` (فحص صارم يوقف عند أي خطأ فك تشفير) —
  **صفر أخطاء** على الملفات الثلاثة بالكامل.
- الفشل الذي بدا في الاختبار الأول كان بسبب أن متصفح الاختبار (Chromium المرفق
  بالبيئة الحالية) هو نسخة مفتوحة المصدر بدون دعم H.264/HEVC أصلًا (قيود ترخيص)،
  وليس بسبب تلف حقيقي بالملفات. أي متصفح حقيقي (Chrome, Edge, Safari, Firefox,
  متصفحات الجوال) يدعم H.264 القياسي هذا بلا مشاكل.

نفس الاستنتاج ينطبق على ملفات `hf_*.mp4` الأصلية — فحصها كشف أنها بترميز HEVC
10-bit (غير مدعوم في أغلب متصفحات الويب أصلًا، بعكس H.264)، وليست تالفة. أُعيد
ترميز نسخة منها إلى H.264 قياسي (`-g 48`) للتأكد من إمكانية استخدامها كبديل عند
الحاجة، لكن تم الاستغناء عنها لصالح `scene1-ivory.mp4` الموجود مسبقًا وبنفس
المحتوى (سبيكة ذهب ١ أونصة تدور).

## أصول غير مستخدمة حاليًا (مستبعدة من حزمة Vercel عبر `.vercelignore`)

مستبعدة من `.vercelignore` فقط لتقليل حجم كل نشر (تُخدَّم أصلًا من GitHub مباشرة
أو غير مُستخدمة إطلاقًا بالموقع) — وليس لأنها تالفة:

- `alzuman-bar.glb`, `alzuman-bar-999.glb` — موديل ثلاثي الأبعاد، للمرجع فقط.
- `scene2-sand.mp4`, `scene3-gold.mp4` — نفس محتوى `scene1-ivory.mp4` (سبيكة تدور)
  بخلفية بلون مختلف (رملي/ذهبي بدل العاجي). سليمة وقابلة للاستخدام، لكن الموقع
  يستخدم النسخة العاجية فقط حاليًا لتناسقها مع خلفية الموقع.
- ملفات `hf_*.mp4` — نفس اللقطة تقريبًا بترميز HEVC 10-bit؛ غير مستخدمة لأن
  `scene1-ivory.mp4` (H.264) متوفر جاهز وأخف.

## المنطق التقني المهم

- **فتح نافذة السبيكة (المشهد الثاني)**: يعتمد على `scrollY` بمنطق بكسلي ثابت
  (نسبة من ارتفاع الـ Hero عبر `offsetHeight`/`offsetTop`)، وليس على
  `getBoundingClientRect` الهش. عند الفتح، يُحمَّل فيديو السبيكة ويُشغَّل
  (`muted`, `loop`, `playsinline`) — لا تحميل مسبق قبل الحاجة.
- **السعر الحي**: يبدأ من 4183.40$ للأونصة ويتذبذب عشوائيًا ±2.4$ كل 5 ثوانٍ.
- **حاسبة الوزن**: السعر = `((سعر الأونصة + 50) / 31.1035) × 3.75 × الوزن بالغرام`،
  ويُعاد حسابه تلقائيًا مع كل تحديث لسعر الأونصة.
